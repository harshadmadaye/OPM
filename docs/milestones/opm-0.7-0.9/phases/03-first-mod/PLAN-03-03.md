<objective>
Hold destructive commands before they run: a tool.call mod hook that pauses `rm -rf` on root-like or out-of-repo paths, a force-push to main or master, and `git reset --hard`, asks the user with $.ui.ask to proceed or cancel, and denies with a reason Claude can act on when nobody can answer. If the guard itself fails, it fails closed.
</objective>
