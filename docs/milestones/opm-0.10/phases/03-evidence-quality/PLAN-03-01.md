<objective>
Every check says where it ran (spec item 10). The verification gate records `env: unit | simulator | physical-device | prod-like` per check. Performance, startup, battery and network claims backed only by a simulator (or unit) run are reported as "not judgeable", never as a pass. A milestone's definition of done can require a real-environment pass, and then phase or milestone close needs at least one check labelled physical-device or prod-like. An unlabelled check in an old report reads as "env: not stated", not as a failure.
</objective>
